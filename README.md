# The Verwood, Plot 269

Interactive 3D home tour for The Verwood at Ashby Fields, Bloor Homes.

Live: https://nottsaifuture.github.io/Verwood/

Drag to orbit, scroll to zoom. Choose a floor to see inside, or start the
walkthrough and use W A S D with the mouse to look around.
